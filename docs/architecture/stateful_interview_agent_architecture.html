Stateful Interview Agent Architecture

Local-first full-stack system for stateful code-understanding interviews. The runtime combines a React operator console, a FastAPI + LangGraph orchestration backend, SQLite persistence, repository grounding against local/Git sources, and pluggable LLM/OpenCode integrations.

Operator Experience

  • • React console manages sessions, turns, analytics, run traces, and bilingual UI.
  • • The frontend is a thin client over typed REST endpoints.
  • • Human review is a first-class orchestration input, not just display metadata.

Core Orchestration

  • • FastAPI routes drive LangGraph workflow execution for each next-question or regeneration run.
  • • Service-layer modules handle planning, validation, coverage rebuilding, summarization, and repo grounding.
  • • Prompt assets are stored as YAML and rendered through a typed prompt manager.

Persistence And Integrations

  • • SQLite persists project state, turns, question versions, token usage, and run-step traces.
  • • The app can ground questions on local or Git repositories by searching and reading focused code snippets.
  • • LLM backends are pluggable: OpenAI-compatible, Anthropic, and local OpenCode automation.
