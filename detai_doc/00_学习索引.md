# Stateful Interview Agent 学习索引

这个目录现在只保留两类真正有长期价值的文档：

1. **Harness Engineering 学习手册**
- 面向 AI 初学者
- 讲理论、分层思想、工程方法、迁移性

2. **单文件 / 单函数深拆文档**
- 面向要深入读代码、改代码的人
- 讲函数级细节、关键分支和修改切口

之前那批偏“概览导读式”的 01-07 已经移除，避免和新的 Harness 手册重复，也避免继续把学习路径带回“先泛泛扫文件”的旧模式。

---

## 一、推荐的主学习路径

如果你是第一次系统学习 AI Agent 工程，按这个顺序最合适：

1. [04_Harness_Engineering_学习总览.md](04_Harness_Engineering_学习总览.md)  
   先建立什么是 Harness Engineering 的整体认识。

2. [05_Harness_Engineering_后端骨架与主链路.md](05_Harness_Engineering_后端骨架与主链路.md)  
   看一个 agent 后端为什么要分层，以及一次 run 如何流转。

3. [06_Harness_Engineering_状态_规划_校验三件套.md](06_Harness_Engineering_状态_规划_校验三件套.md)  
   这是最重要的通用工程模式。

4. [07_Harness_Engineering_人机协作与前端闭环.md](07_Harness_Engineering_人机协作与前端闭环.md)  
   看 human review 为什么必须进入前后端闭环。

5. [08_Harness_Engineering_可观测性_运行轨迹_调试方法.md](08_Harness_Engineering_可观测性_运行轨迹_调试方法.md)  
   看 agent 为什么必须可追踪、可排障、可解释。

6. [09_Harness_Engineering_从本项目迁移到通用AI_Agent.md](09_Harness_Engineering_从本项目迁移到通用AI_Agent.md)  
   看哪些结构可以迁移到别的 AI Agent。

7. [10_Harness_Engineering_如何实操修改一个Agent.md](10_Harness_Engineering_如何实操修改一个Agent.md)  
   学会以后怎么判断问题属于哪一层、该从哪改。

8. [11_Harness_Engineering_从零搭建一个最小可用Agent.md](11_Harness_Engineering_从零搭建一个最小可用Agent.md)  
   学会不用照抄仓库，也能自己从 0 搭一个最小可用 harness。

9. [12_案例_如何抑制重复问题.md](12_案例_如何抑制重复问题.md)  
   用真实问题学习如何从状态、规划、检索、校验四层一起压重复率。

10. [13_案例_如何让human_review真正影响planner.md](13_案例_如何让human_review真正影响planner.md)  
   用真实问题学习如何把 human review 从 UI 真正接进 planner 和 transcript。

11. [14_案例_如何给Agent增加一个新阶段.md](14_案例_如何给Agent增加一个新阶段.md)  
   用真实改造任务学习阶段为什么是一个跨 state / planner / prompt / validator / UI 的全栈 contract。

12. [15_专题_如何设计Agent的状态Schema.md](15_专题_如何设计Agent的状态Schema.md)  
   讲 agent 的状态为什么不应只是一串历史消息，以及怎样把状态设计成能服务规划和校验的 contract。

13. [16_专题_如何设计Planner输出契约.md](16_专题_如何设计Planner输出契约.md)  
   讲 planner 为什么应该输出结构化 contract，而不是只返回一句模糊自然语言。

14. [17_专题_如何设计Validator而不是只调Prompt.md](17_专题_如何设计Validator而不是只调Prompt.md)  
   讲 validator 在 agent 工程里的角色，以及为什么它是质量边界而不是附属层。

15. [18_专题_如何设计ExecutionTrace前后端契约.md](18_专题_如何设计ExecutionTrace前后端契约.md)  
   讲如何把系统执行过程抽象成前后端都稳定、用户也能看懂的 execution trace contract。

16. [19_专题_如何设计Prompt资产系统.md](19_专题_如何设计Prompt资产系统.md)  
   讲 prompt 为什么应该资产化、schema 化，而不是继续散落在业务代码里。

17. [20_专题_如何设计Agent的记忆压缩与检索.md](20_专题_如何设计Agent的记忆压缩与检索.md)  
   讲 agent 如何把历史压缩成结构化证据，并在当前目标下做选择性检索。

18. [21_专题_如何设计Human-in-the-loop产品交互.md](21_专题_如何设计Human-in-the-loop产品交互.md)  
   讲 human review 的产品交互如何真正形成低负担、真生效、可见证的闭环。

19. [22_专题_如何把单轮应用演进成多轮可交付Agent.md](22_专题_如何把单轮应用演进成多轮可交付Agent.md)  
   讲如何从单轮 LLM 应用逐步演进到有状态、可规划、可追踪、可协作的多轮 agent。
